# 💰 BudgetWise - Budget Planner with Charts

A responsive monthly budget planner built using HTML5, CSS3,
JavaScript, Chart.js and LocalStorage.

## 📌 Project Overview

BudgetWise helps users manage their monthly finances by allowing
them to set category-wise budgets, record expenses and compare
budgeted amounts with actual spending.

The application also highlights categories that exceed their
allocated budget.

## 🎯 Objective

The objective of this project is to practice:

- Data aggregation
- JavaScript forms
- Array.reduce()
- Chart visualization
- LocalStorage
- Responsive web design

## 🚀 Features

- Set budget per category
- Add expenses
- Categorize expenses
- Budget vs Actual chart
- Over-budget warning
- Category progress indicators
- Total budget calculation
- Total spending calculation
- Remaining balance calculation
- Recent expenses
- Monthly reset
- LocalStorage persistence
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- LocalStorage
